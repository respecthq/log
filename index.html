03 — FEATURES

思考が育つ、
6つの仕組み。

FROM NOTE TO NEXT MOVE記録して終わらず、次の行動へつながるところまで。Logは思考の流れ全体をひとつの体験にします。
01 / CAPTURE

一行で記録

考えが消える前に、最小の操作で残す。整理はあとからで大丈夫。

02 / CONNECT

関連ログ・思考の履歴

過去のログを結び、どこから考えが生まれたかを残します。

03 / DEEPEN

AIと深掘り

3つのAIと対話し、別の視点や次に考えるべき問いを増やします。

05 / VISUALIZE

Spiral Graph™

思考の密度・深さ・到達率を、Log独自の対数螺旋で可視化します。

06 / EXPORT

フォルダごとZIPで書き出し。1ログ＝1つのMarkdownファイルなので、他のメモアプリやエディタにそのまま持ち込めます。

05 — LAYERS

思考の
6つの段階。

ひらめきから到達まで。Logは、思考の進化を6つのレイヤーで追跡します。

  1. 01IDEAひらめく

    気づき、疑問、直感を一行で残す。

  2. 02OUTPUT書き出す

    頭の中のもやを、扱える言葉にする。

  3. 03BUILD構造化する

    点を線に、線を面にして関係を見る。

  4. 04LAUNCH外へ出す

    小さく公開し、反応から次を見つける。

  5. 05REVIEW振り返る

    起きたことを観測し、意味づける。

  6. 06REACH到達する

    次の螺旋を始める起点をつくる。

07 — WHY “LOG”

Logは、記録。
そして、対数。

増えすぎる情報を、人間が扱える思考に変える。

log(記録) = 構造 = 思考可能

Logは、思考を保存するだけではありません。複雑になった思考を、もう一度扱える形に変換します。
